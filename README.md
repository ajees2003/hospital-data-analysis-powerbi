# Blood Bank Data Analysis & Power BI Dashboard

## 📊 Project Overview

This project focuses on analyzing blood bank data and developing an interactive dashboard using Microsoft Power BI.

The dashboard provides insights into blood orders, blood groups, donations by age group, hospital revenue, location-wise revenue, and agent performance.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## 🔍 Key Analysis

- Total blood orders and units analysis
- Most demanded blood group analysis
- Blood donation by age group
- Hospital-wise revenue analysis
- Location-wise revenue analysis
- Top-performing agent analysis
- Blood bank performance overview

## 📈 Dashboard Highlights

The dashboard includes interactive visualizations for:

- Total Orders
- Total Units
- Total Revenue
- Most Demanded Blood Groups
- Blood Donation by Age Group
- Total Revenue by Hospital
- Revenue by Location
- Top 3 Agent Performance

## 🎯 Project Objective

The objective of this project is to transform blood bank data into meaningful business insights and present the information through an interactive Power BI dashboard.

The dashboard helps users understand demand patterns, revenue performance, donor demographics, and operational performance.

## 💡 Key Insights

- B+ve is the most demanded blood group in the analyzed dataset.
- The 40–60 age group represents the highest share of blood donations.
- Bewell Hospital contributes the highest revenue among the hospitals shown.
- Location-wise revenue varies across different hospital locations.
- The dashboard highlights the top-performing agents based on revenue.
